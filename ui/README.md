# Chatbot UI

Frontend modern AI Chatbot interface yang dibangun dengan React + Vite + TypeScript.

Untuk dokumentasi lengkap, silakan lihat [README utama di parent directory](../README.md).

## Quick Start

```bash
# 1. Pastikan file .env sudah sesuai
cp .env.example .env

# 2. Install dependensi
npm install

# 3. Jalankan server dev
npm run dev
```

Server akan berjalan di `http://localhost:5173`.
